# PeerPoint — 网站展示版（Demo）

课堂演示用的可点击原型。**零依赖、零构建、零后端**，双击 `index.html` 就能跑。

---

## 一、怎么打开

| 方式 | 操作 |
|---|---|
| **最简单** | 双击 `index.html`，用 Chrome / Safari 打开 |
| **本地服务**（推荐，路由更干净） | 在本文件夹运行 `python3 -m http.server 8777`，然后打开 http://127.0.0.1:8777 |
| **放到网上** | 整个 `PeerPoint/` 文件夹丢进 GitHub Pages 即可，无需改任何代码 |

> 你机器上现在**已经有一个服务在跑**：http://127.0.0.1:8777/index.html（进程 PID 6590）。
> 关掉它：`kill 6590`

**无需联网也能用**——字体走 Google Fonts，断网时自动降级到系统衬线/无衬线字体，版式不会崩。

## 二、两分钟演示脚本

> 提前按一次右上角 **Reset demo**，从干净状态开始。

| 时间 | 你点什么 | 你讲什么 |
|---|---|---|
| **0:00** | 打开首页，停在首屏 | "PeerPoint 解决的是一个很具体的问题：你看懂了整章，但**就有一道题卡住**。看答案、看视频，还是说不清自己错在哪一步。" |
| **0:15** | 点 **Try a sample problem** | （避免现场打字）"学生提交题目、自己的解法，以及**卡在哪一步**。" |
| **0:35** | 点 **See mentor matches** | "我们不按'谁成绩好'匹配，而是按**这个知识点**匹配。" |
| **0:50** | 指着 **Suggested for your topic** 和那句推荐理由 | "注意推荐理由是**具体的**——Alex 擅长机会成本，用的是分步表格。" |
| | 点任意 **View profile**，看完按 **Esc** 关闭 | "导师资料是**虚构的演示资料**——没有虚构的评分、课时数或认证徽章，因为我们还没验证过。" |
| **1:10** | 点 **Choose mentor** → 选一个时段 → 勾选学习原则 → **Confirm demo booking** | "预约页写清楚：**不收费、不真的排课**。价格是拟定的试点价 ¥49。" |
| **1:30** | 点 **Preview session** 展开课堂示意 | "这是课堂的**静态示意**——不申请摄像头麦克风权限，也没有任何真实通话。" |
| **1:45** | 点 **Finish demo session & practise** | "最关键的一步：**辅导之后，学生要自己做一道新题。**听懂 ≠ 会做。" |
| **2:00** | 选答案 → **Check my answer** → 看批改 | "答对答错都有对应讲解和算式。" |
| **2:15** | 点 **See my session summary** | "总结引用的是**刚才真实的作答结果**，并且明确写了这个原型**不声称**什么——不预测提分、不预测 AP 分数。" |
| **2:30** | 点右上 **My learning** | "本次演示产生的记录，状态从 Booked → Practice ready → Practice completed。" |

**收尾一句话**："Bring one problem. Practise the next one independently."

## 三、演示时需要提前说的三句话（诚实性）

这个原型的**卖点之一就是它不乱吹**。建议主动讲：

1. **"导师资料是虚构的演示数据，没有经过认证。"** —— 页面自己也这么标注。
2. **"¥49 是待验证的试点假设价。"** —— 页面上写的是 "Proposed pilot price"。
3. **"我还没有做用户访谈，所以这里没有任何提分率、好评或合作学校的声称。"**

这三条不是缺点，是加分项——任务书里明确要求"不要加入未经验证的用户规模、提分率、五星评价、媒体背书或学校合作关系"。

## 四、可能被问到的问题

| 老师可能问 | 怎么答 |
|---|---|
| "导师怎么筛选？" | 科目背景核实 + **简短试讲**。页面明说"高分不等于会教"。 |
| "怎么保证不是帮你写作业？" | 预约前必须勾选："This session is for learning and practice, not completing graded work for me." 而且每节课结尾有**学生自己的独立练习**。 |
| "¥49 里你赚多少？" | 这是**价格假设**，不是利润表。导师报酬、匹配时间、备课、客服、退款、获客成本都还没测。 |
| "为什么学生不用免费的 AI 或视频？" | 通用讲解回应不了**你这道题里具体错在哪一步**。提交自己的错误推理，才是这个服务的输入。 |
| "为什么只做一所学校、一个科目？" | 先验证需求再扩展——这是任务书里定的第一阶段范围。 |
| "有几个人试用过？" | **还没有。** 已验证的下一步是访谈 ≥5 位学生，再跑 5 学生 + 2 导师的小规模试点。 |

## 五、技术说明（如果被问到实现）

- **纯静态**：`index.html` + `styles.css` + `app.js` + `data.js`，没有构建步骤、没有依赖包
- **路由**：hash 路由（`#/request`、`#/booking/alex`…），直接访问缺数据的页面会**自动引导回提交页**
- **状态**：`sessionStorage`（关掉标签页即清空）；上传的图片**只存在内存里**，不上传、不持久化
- **日期**：从**当天**动态生成未来 7 天，标注 China Standard Time (UTC+8)；已过去的时间段不提供
- **无后端**：不接支付、不接视频、不接数据库、不调用任何 AI 模型
- **可访问性**：表单有 label 和字段级错误提示、弹窗支持 Esc 关闭并把焦点还给触发按钮、状态不只靠颜色区分（都有图标+文字）、支持键盘导航

## 七、文件清单

```
PeerPoint/
├── index.html   ← 入口（双击这个）
├── styles.css   ← 设计系统：#F7F5F0 纸白 / #203E4A 深蓝 / #BF8952 暖金
├── data.js      ← 本地演示数据：5 个知识点、3 位虚构导师、5 道原创练习题

└── README.md    ← 本文件
```

**练习题都是原创的**（每个知识点一道，含正确选项与解析），不是从真题或题库里抄的。
